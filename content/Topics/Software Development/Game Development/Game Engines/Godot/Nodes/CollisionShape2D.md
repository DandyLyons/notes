A node that provides a [Shape2D](https://docs.godotengine.org/en/stable/classes/class_shape2d.html#class-shape2d) to a [[CollisionObject2D]] parent and allows to edit it. This can give a detection shape to an [Area2D](https://docs.godotengine.org/en/stable/classes/class_area2d.html#class-area2d) or turn a [PhysicsBody2D](https://docs.godotengine.org/en/stable/classes/class_physicsbody2d.html#class-physicsbody2d) into a solid object.
