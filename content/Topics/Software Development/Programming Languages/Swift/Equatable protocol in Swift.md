An Equatable conformance should fulfill the [Reflexive relation](https://en.wikipedia.org/wiki/Reflexive_relation) property meaning: 
1. `a == a` is always `true` (Reflexivity)
2. `a == b` implies `b == a` (Symmetry)
3. `a == b` and `b == c` implies `a == c` (Transitivity)
