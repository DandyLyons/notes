Swift provides [swift-log](https://swiftpackageindex.com/apple/swift-log) which is the cross platform open source logging system. This provides the primitives for logging but really you should be using [one of the many logging backends which are built on top of swift-log](https://github.com/apple/swift-log#available-logging-backends-for-applications).
