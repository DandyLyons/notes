With the advent of [[LLM]]s, it is now vastly easier to perform average note taking tasks such as: 
- summarizing long text into a concise outline
- visualizing concepts as a mind map
- extracting: 
	- key insights
	- actionable next steps
	- key principles
	- valuable lessons
- Rephrasing in a way that is more appropriate for a different context. (e.g. formal/informal, academic, friendly, marketable etc.)
- translating to other languages
- ask specific questions
