## My notes
Five features every good [[task management]] system should have:

1. **R**eliable - System must be trustworthy
	1. If you don’t trust it, comma you won’t use it.
2. **E**xternal - Get tasks out of your head
	1. Don’t rely on memory
3. **D**oable - Tasks should be clear and actionable
	1. Asks should require minimal interpretation
	2. It should be [[glanceable]]
4. **E**xhaustive - there should be only one central place for all tasks
5. **E**ngaging - System should invite focused work
	1. It should **invite** You to do Focused Work. 
	2. It should not overwhelm or confuse you  
	3. Make it so you **want** to use your system. 
6. **M**anageable - Simple enough to provide clarity
