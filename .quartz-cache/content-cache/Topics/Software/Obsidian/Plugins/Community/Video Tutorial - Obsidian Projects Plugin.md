## Notes
### [00:00](https://www.youtube.com/watch?v=aFfREf9IQ7Q&t=0s) Introduction
- the plugin "watches" a collection of notes and displays them in "nice" views like [[Notion]]. 
- **Which notes will be watched?** You can watch notes according to: 
	- all notes in a *folder*
		- You can choose whether or not to allow subfolders
	- all notes with a *tag*
	- all notes returned from a [[Topics/Software/Obsidian/Plugins/Community/Dataview/index|Dataview]] query
- **What kind of "*views*" can I use?** Notes can be viewed as: 
	- a table 
	- a calendar
	- a [[Kanban]] board
	- a gallery
