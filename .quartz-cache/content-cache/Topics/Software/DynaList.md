## Keyboard Shortcuts

| Shortcut                | Action                       |
| ----------------------- | ---------------------------- |
| Command-?               | Open help                    |
| Command-Shift-Backspace | Delete item (line)           |
| Shift-Enter             | Switch between item and note |
| Command-Enter           | Mark as done                 |
| Command-Shift-Enter     | Start new line               |
| Command-Period          | Expand/collapse              |
| Command-Shift-Period    | Expand/collapse all          |
| Command-Shift-C         | Toggle checklist             |
| Command-Shift-X         | Toggle numbered list         |
| Command-Shift-A         | Select everything            |
| Command-]               | Zoom in                      |
| Command-[               | Zoom out                     |
| Command-Backtick        | Code                         |
| Command-Shift-H         | Toggle heading               |
| Command-Shift-L         | Toggle color label           |
| Command-F               | Search within document       |
| Command-Shift-F         | Toggle file pane             |
| Command-Shift-B         | Toggle bookmark pane         |
