## How to Use Bookmarklets on Arc
Arc doesn't have a bookmarks bar, but you can still go to `arc://bookmarks` and manually add a bookmark/bookmarklet

To run or go to a bookmark you can use an extension like Powerlet ([https://chromewebstore.google.com/detail/powerlet/ofecodkcadbenmiknnidnfepbblapgkn](https://chromewebstore.google.com/detail/powerlet/ofecodkcadbenmiknnidnfepbblapgkn)) with which you can run the media notes bookmarklet. [^1]
