Thesis: Representation does matter, but not as much as you think it does. 
## The Value of Representation
Representation dispels the myth "I can't do it". 
Representation helps us to overcome **limiting beliefs**. 
Representation teaches us the lesson "If they can do it, then so can I". 
But representation is not the only way to learn this lesson. 

## Observation: There Is A First For Everything
Everything that has ever been done, must've been done a first time. Somebody was the first. 

## You Can Be A First Too
If all these other people could be first, why can't you be a first? 
Why do you need to wait for someone else to be a first. 
Learn from, and be inspired by other firsts. 

## Representation From Other Firsts
Despite this pep talk, it is still difficult to overcome **limiting beliefs**. Especially if you have immense challenges. So what should we do? 

Remember that **no challenge is truly unique**. Whatever problem you have, **someone** else has had it before. You are not the first to have this problem. Even if you are the first person to have your **specific** problem, others have had parts of your problem before. Learn from others who overcame similar problems. 

Are you disabled? Learn from other disabled people. Are you oppressed? Learn from others who have endured the same oppression.
