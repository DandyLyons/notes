A scripting language is a type of [[Topics/Software Development/Programming Languages/index|Programming Language]] designed for relatively short and simple set of instructions that typically [automate](https://en.wikipedia.org/wiki/Automation "Automation") an otherwise manual process.

Originally, scripting was limited to automating an [operating system shell](https://en.wikipedia.org/wiki/Operating_system_shell "Operating system shell") and languages were relatively simple. Today, scripting is more pervasive and some languages include modern features that allow them to be used for [application](https://en.wikipedia.org/wiki/Application_software "Application software") development as well as scripting.
