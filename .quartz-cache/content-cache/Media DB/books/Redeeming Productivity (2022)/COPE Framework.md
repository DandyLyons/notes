### The Five Essential Lists

2. Projects list

4. Future list

#### Inbox
- This is where you [[capture]] tasks. 
- This list should be [[ephemeral]]. 
#### Projects list
- If a task requires multiple steps, then it's not a [[tasks|task]]. It is a [[Projects|project]]. 
- This is a list of all the projects that need to be completed. 

#### Actions list
- The actions list comprises of all of the **individual actions** that you need to **do** in order to complete a [[Projects|project]].
